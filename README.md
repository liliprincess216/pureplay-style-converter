# 纯玩风格转换器

上传照片，保留明显的人物主体，将背景转换为具有粗细节奏和色彩变化的横向条带；没有明显人物时生成完整条带背景。支持滑动查看结果和点击下载。

## v25 固定存档

`v25-archive` 是用户确认保留的版本，包含条纹上传页、三行像素「纯玩」依次跳动的等待页，以及当前的生成效果与交互。

后续开发不得移动或覆盖此标签。新修改在独立开发分支进行；原版可随时从此标签取回。

## v27 完整 H5

`v27` 保存完整长页：七张企划海报依次展示，底部接入转换器。左滑查看结果，右滑返回原图，上下滑动浏览企划。

首页打开完整 H5；`converter.html` 可单独打开转换器。v25 存档不受影响。

此版本尚未加入 HEIC 专用转换兜底。境外模型依赖及微信内兼容性需要在目标设备与网络实测。

## 本地运行

在项目目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

访问 `http://127.0.0.1:4173/`。图像识别依赖在线加载的第三方库与模型，因此首次使用需要联网；本存档不包含这些远程模型。

本仓库未授予代码或设计素材的额外使用许可。
